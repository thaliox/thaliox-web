# 快速上手

THALIOX 本体是一个 Rust workspace。先把仓库跑起来,再让一个 agent 自主完成任务。

## 前置

- Rust 1.96+(`rustup`)
- 一个 LLM provider 的 API key(Anthropic 或任意 OpenAI 兼容网关)

## 克隆与构建

```bash
git clone https://github.com/thaliox/thaliox-os.git
cd thaliox-os
cargo build --workspace
```

## 跑一个自主 agent

给定目标,模型自己决定调哪个工具(`web_search` / `fetch`)、执行、把结果喂回、再思考,直到给出答案:

```bash
OPENAI_API_KEY=...  OPENAI_BASE_URL=...  THALIOX_MODEL=glm-5.1 \
  TAVILY_API_KEY=...  cargo run -p thaliox-runtime --example autonomous_agent
```

无 key 时会退化为脚本化 mock,演示同一条闭环。
