# 核心概念

## TAM 三原语

THALIOX 抽象机(TAM)用三个第一性原语定义整个系统:

| 原语 | 取代 | 含义 |
|---|---|---|
| 向量消息 | 文件 / 字节流 | agent 间交换"意义"的单位 |
| 注意力预算 | CPU 时间片 | 调度与资源核算的单位(token) |
| 能力令牌 | uid / gid | 权限与信任的单位 |

## 五不变量

任何实现(软件或硅)都必须满足:

1. **INV-1 预算守恒** —— 思考/行动按预留扣减,执行后对账到真实 token,失败退款。
2. **INV-2 能力前置** —— 任何副作用前校验签名 + 过期 + scope。
3. **INV-3 向量保真** —— 记忆经语义空间存取,不降维成字符串键。
4. **INV-4 可审计** —— 每次调用落审计记录。
5. **INV-5 人类底线** —— 可撤销、可接管、可回滚,主权在人。

## 八 crate

| crate | 职责 |
|---|---|
| `core` | TAM 原语 + 五不变量 + 契约 |
| `runtime` | agent 执行、生命周期、自主 tool-calling 循环、审计 |
| `memory` | 语义空间 + 四层记忆 |
| `cognition` | 统一 LLM 接口 + tool-calling 渲染解析 |
| `tools` | agent 可调的工具(web_search / fetch) |
| `fabric` | agent↔agent 协作(M4 起) |
| `cap` | 能力令牌签发/验证 |
| `api` | 统一 API 网关 |

详见 [thaliox-os 仓库](https://github.com/thaliox/thaliox-os) 与 [M1 里程碑总结](https://github.com/thaliox/thaliox-os/blob/main/docs/M1-MILESTONE.md)。
